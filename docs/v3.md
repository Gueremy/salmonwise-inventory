# SalmoTrack v3

Continuación de `feat/frontend-v2-integration-fixes` (832273a), compatible con la rama `v3` de `Gueremy/AXIOUS`.

Incluye modo evidencia reversible, preparación offline por usuario, autorización de escritura de 72 horas, entradas/salidas/traslados y lotes nuevos, sincronización recuperable e idempotente, QR estable con fallback JS y resolución offline, historial legible y exportaciones completas.

Validación local: 40 pruebas frontend, TypeScript y build aprobados. Playwright: diez recorridos aprobados en Chromium de escritorio y Pixel 7 emulado, contra backend real con datos sintéticos. El backend compatible pasa 168 pruebas SQLite y 11 PostgreSQL, incluida exportación de 20.002 movimientos.

El workflow Browser integration permite ejecutar los recorridos con `backend_ref=v3`. El despliegue debe configurar `VITE_API_BASE_URL` con la URL HTTPS del backend compatible; no usar localhost para un frontend público. El Service Worker requiere HTTPS y conserva la cola durante las actualizaciones explícitas.

Power BI Desktop/Service, dispositivos físicos, prueba real de 72 horas y piloto con operarios permanecen pendientes. No se incluyen credenciales ni datos productivos.
